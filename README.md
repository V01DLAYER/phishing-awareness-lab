# Phishing Awareness Lab

## Overview

This project explores how phishing pages are created and why they remain one of the most successful social engineering attack vectors.

The objective was to understand phishing techniques in a controlled lab environment and learn how attackers attempt to collect user credentials through deceptive web pages.

## Topics Covered

* Social Engineering Fundamentals
* Phishing Attack Lifecycle
* Credential Harvesting Techniques
* Detection and Prevention Methods
* User Awareness Best Practices

## Learning Outcomes

Through this lab, I gained a better understanding of:

* How phishing campaigns operate
* Common indicators of malicious websites
* Risks associated with credential theft
* Defensive measures for individuals and organizations
* The importance of security awareness training

## Disclaimer

This project was conducted strictly in a controlled educational environment for cybersecurity learning purposes. No real users, production systems, or unauthorized targets were involved.
